# Scope

## In scope — Pilot (Phase 1)
- One security desk / location.
- Guard intake, lost reports, matching, claims, admin review, pickup, disputes.
- Expiry, retention, notifications, audit, backups.
- LLM assistant and CV object detection OFF by default (feature flags).

## In scope — Later phases
- More locations, better matching tuning, analytics dashboard.
- Optional LLM prefill / CV suggestions after approval and stability.
- Drop-off QR ticket for finders (optional idea).

## Out of scope (v1)
- Peer-to-peer item holding / meetup.
- Public browsing of found items.
- Multi-campus support.
- Native mobile apps (responsive web only).
- Payments / rewards.
- Guard-location permission scoping (all active guards permitted in v1).

## Assumptions & dependencies
- AU SSO available and roles mappable.
- AU-approved object storage and email provider.
- Admin approves pilot scope and categories.
