# Design System

## Principles
Simple, fast, plain-language, mobile-first, accessible.

## Branding
- Use AU official branding with permission.
- Neutral surfaces; color reserved for status and actions.

## Status colors (consistent everywhere)
- READY_FOR_PICKUP / RETURNED / SUCCEEDED → green
- PENDING_REVIEW / PROCESSING / NEEDS_PROOF → amber
- DISPUTED / REJECTED / FAILED / EXPIRED(alert) → red
- Neutral statuses → gray

## Typography & spacing
- System font stack; 16px base; clear hierarchy; generous touch targets (≥44px).

## Accessibility (WCAG 2.1 AA)
- Keyboard navigable; visible focus; screen-reader labels; contrast ≥ 4.5:1;
- forms with inline errors; no color-only meaning.

## Voice & tone
Plain language, no jargon. Example: "Your item is ready for pickup" not "Claim state READY_FOR_PICKUP".
