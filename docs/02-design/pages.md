# Pages

## Common
- Login (SSO redirect) | Consent screen | Support/contact page

## Guard
- **Intake screen**: photo capture, category/location/storage/label selects, upload progress, submit. States: empty/uploading/error(rejected)/success.
- **Handover screen**: code entry, ID check checkbox, verify button, escalate button. States: valid/failed/locked/disputed.

## Student
- **Lost report form**: structured fields; optional assistant toggle; private detail field (marked private).
- **My reports / matches**: match cards with blurred teaser + "not mine" action.
- **Claim status**: timeline (pending/ready/returned/expired), pickup deadline/location, code/QR, original photo button (only when allowed), support link.

## Admin
- **Pending claims queue**: filter by status/category; count badges.
- **Claim review**: item + report details, score breakdown, approve/reject with reason, dispute resolution.
- **Items search**: status/category/location filters.

Every page defines: purpose, primary action, empty/loading/error/success states.
